# Documentation

These pages describe this template. Read the page that matches the task.

| Page | Use it when you want to |
| --- | --- |
| [Start](start.md) | Clone the repo, install, and open the site |
| [Brand](brand.md) | Change the name, author, colors, and images |
| [Posts](posts.md) | Add a post, series, translation, or draft |
| [Pages](pages.md) | Edit About, Now, Colophon, or another page |
| [Publish](publish.md) | Build the site, set the public URL, and ship it |
| [Layout](layout.md) | Find a file in the repository |

[`llms.txt`](../llms.txt) in the repository root lists the same pages for agents. `public/llms.txt` is the same file, so a published site serves it at `/llms.txt`.

When a behavior changes, update the matching page in this folder in the same change.
