# Documentation

Guides for this template. Each page links to the others. Start at the top when the site is new, or open the page that matches the task.

[Start](start.md) · [Brand](brand.md) · [Posts](posts.md) · [Pages](pages.md) · [Publish](publish.md) · [Layout](layout.md)

## Read in order

| Step | Guide | You will be able to |
| --- | --- | --- |
| 1 | [Start](start.md) | Clone the repo, install, and open the local site |
| 2 | [Brand](brand.md) | Set the name, author, colors, navigation, and images |
| 3 | [Posts](posts.md) | Add a post, a series, a translation, or a draft |
| 4 | [Pages](pages.md) | Rewrite About and add pages such as Now |
| 5 | [Publish](publish.md) | Build `dist/`, set the public URL, and ship the site |
| 6 | [Layout](layout.md) | Find a file or a route when you need to look something up |
