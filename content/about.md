# About

This site is powered by **OpenBlog** — a free, open-source blogging template.

## In short

- **Free** to use for your own blog
- **Open source** on GitHub
- **File-based** — posts are Markdown (`.md`) files
- **GitHub-based** — write, review, and publish from a repository
- **MIT licensed** — use it, change it, make it yours

## For readers

Browse the starter posts to learn what OpenBlog is. Use categories, tags, the year archive, and search when you want a specific article. RSS, Atom, and JSON feeds are linked from the footer.

Pages such as Now, Colophon, and Uses are Markdown files in `content/pages/`.
