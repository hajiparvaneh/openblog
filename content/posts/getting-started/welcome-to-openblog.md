OpenBlog turns Markdown files in Git into a public blog.

## What you get

- Posts under `content/posts/<category>/<post>.md`
- Branding from `openblog.config.ts` and `public/branding/`
- A static site you can deploy to GitHub Pages with no API secrets

## Next step

Edit [Your first post](/posts/getting-started/your-first-post) or create a new Markdown file, open a pull request, and merge it to publish.
