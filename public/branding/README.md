# Branding assets

Replace these files to brand your blog. Paths are referenced from `openblog.config.ts`.

| File | Purpose |
| --- | --- |
| `logo-light.png` | Header logo (light surfaces) |
| `logo-dark.png` | Header logo (dark header / dark theme) |
| `favicon.ico` | Browser favicon |
| `favicon-32x32.png` | PNG favicon |
| `apple-touch-icon.png` | Apple touch icon |
| `og-default.png` | Default Open Graph image |

Keep filenames the same, or update the paths in `openblog.config.ts`.
